## 三、迁移脚本开发 ✅

**新增脚本**：`scripts/migrate-canvas-base64.js`

**功能**：
- `--dry-run` 模式预览（默认）
- `--execute` 模式执行（需 `--backup`）
- 支持 `--table`、`--id`、`--limit` 参数
- 自动校验 mime 类型（png/jpeg/webp）、大小（≤10MB）
- 生成 JSONL 备份文件
- 更新 `canvas_meta` 含 asset refs

**安全限制**：
- 默认 dry-run，无 `--execute` 不写文件不更新 DB
- `--execute` 必须配合 `--backup`
- 单次 limit 上限 50
